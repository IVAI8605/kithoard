### V0.3 第三批：Pexels 第二个源与按源分组

| 项 | 落点 |
|---|---|
| Pexels 适配器 | `src/main/sources/pexels.ts`：图片 `/v1/search`、视频 `/videos/search`，Key 走 `Authorization` 头；视频优先 1280–1920 mp4；许可统一 `free` |

| 配置 | `READABLE/WRITABLE_SETTINGS` 增加 `source.apiKey.pexels`；设置页按来源渲染开关与 Key |
| 渲染层 | `store.groups` 取代单一 `items/result/page`；搜索页按来源分组、组内独立翻页；`saveApiKey(sourceId, key)` |
