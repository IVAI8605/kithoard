### V0.3 第四批：备份导出与导入

| 项 | 落点 |
|---|---|
| 备份格式 | `src/main/backup/format.ts`：`schemaVersion=1`，含 assets / favorites / downloads / localFiles / settings；收藏与下载只记 `(sourceId, remoteId)`，不信任本地自增 id |
| 导出 | `src/main/backup/index.ts` 的 `buildBackup`：只读库；settings 只导出 `source.enabled` / `download.dir` / `download.concurrency`，`source.apiKey.*` 永不出现 |

| 校验 | `parseBackupJson` 在写库前完成；非法 JSON、缺 `schemaVersion`、高版本、字段类型错误一律 `E_RESTORE_INVALID`，库不变 |
| 入口 | `settings:backup` / `settings:restore`；设置页「备份与恢复」支持导出、导入（二次确认）、导入摘要与界面刷新 |
