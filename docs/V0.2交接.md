## 本批刻意没做的（后续补）

1. **本地素材页**：「本地素材」仍置灰，`local_files` 只写不读（§7.4-10）。
2. **真实端到端**：本批只做静态检查与单测，未用真实 Pixabay 素材跑「搜索 → 入队 → 暂停 → 继续 → 完成 / 隔离」全链路。
3. `download:estimate` 通道（下载前预估大小）未实现；`confirmLarge` 依赖 `size_bytes`，Pixabay 不返回大小，实际很少触发（见待定问题 13）。
4. 真实 v2 → v3 迁移冒烟未跑（构造 v2 库升级到 3）。
5. 模板类型下载：当前一律拒绝，等出现真实来源再定白名单。

## 下一批建议：本地素材页 + 真实端到端验证

- 左侧「本地素材」解除置灰：读 `local_files`，按类型筛选、打开文件所在位置、标出 `missing`。
- 用 `cache/.pixabay-key` 跑一次真实搜索 → 快速下载 → 暂停 → 继续 → 完成，核对磁盘文件与库记录。
- 用改名后的可执行文件冒充 `.jpg` 验证隔离 → 恢复 → 放弃全链路。
- 构造 v2 库验证迁移到 v3 的备份与表结构。
