## 本批刻意没做的（下一批补）

1. **下载前安全拦截**：扩展名白名单、可执行/脚本类直接拒绝、大小上限提示（§7.4-5）。
2. **下载后校验与隔离**：目前 `verifying` 只校验大小；魔数、可读性、风险判定与 nil 隔离区尚未落地（§7.4-6）。`quarantined` 状态与恢复/放弃通道还没有入口。
3. **启动恢复接线**：§5.4 决策函数已就绪，但启动时没有扫描与「是否恢复」弹窗（§7.4-9）。
4. **下载管理页与卡片快速下载**：界面仍置灰（§7.4-7/8/14）。
5. `download:estimate` 通道、批量确认框（§7.4-8）。
6. 本批完成即 `completed`；没有安全扫描，因此不存在「风险文件」分支。

## 下一批建议：安全拦截 + 下载后校验/隔离

- 下载前：按扩展名白名单与可执行/脚本黑名单拦截，超大小阈值提示确认（需求四）。
- 下载后：在 `verifying` 内补魔数匹配、可读性检查；高风险文件移入 `userData/quarantine/`，状态 `quarantined`，`local_files.status = quarantined`。
- 新增 `quarantine:restore` / `quarantine:list` 通道；放弃时按 §5.8 移入回收站（`shell.trashItem`）。
- 单测优先：扩展名/魔数判定表、风险判定、隔离路径规则；再接 IPC。

## 环境与红线

- 仓库 `https://github.com/IVAI8605/kithoard`，main 分支；每批过门禁后自行 commit + push，不打 tag、不建 Release、不打包。

- 每批改动前备份到 `cache/backup/`，验证单写 `cache/验证单/v0.2.0.md`（都不进仓库）。
