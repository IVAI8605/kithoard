Windows 素材库软件 PRD 产品需求文档

项目名称： Windows 素材库
产品类型： Windows 桌面应用程序
目标用户： 视频剪辑、数字媒体设计、日常素材整理用户
开发策略： 分阶段开发，优先保证核心功能稳定。

---

一、产品定位

开发一款集素材搜索、网页浏览、素材预览、下载管理、本地素材管理及基础处理工具于一体的 Windows 桌面软件。

用户可以通过软件搜索网络上的图片、视频、音乐、音效、字体、设计模板等素材，在遵守来源网站规则和版权要求的前提下，完成预览、下载、收藏和本地管理。

软件强调：

- 操作简单，界面清晰。
- 搜索方便，素材分类明确。
- 下载稳定，支持断点续传。
- 本地文件管理统一。
- 提供常见素材格式转换和压缩工具。
- 不绕过网站登录、付费或下载限制。

二、软件整体页面结构

主界面采用左侧导航栏 + 右侧内容区域的布局。

1. 首页 / 素材搜索

- 默认启动进入搜索首页。
- 支持关键词搜索。
- 支持按素材类型分类。
- 搜索结果采用统一卡片布局。
- 每页默认显示20条结果。
- 使用传统分页，支持上一页、下一页。
- 支持多选素材。
- 支持批量收藏、批量下载等适用操作。

2. 网站导航

- 支持在软件内部浏览素材网站。
- 支持复制当前网页链接。
- 自动记录最近访问的10个网站。
- 不设置网站导航收藏功能。
- 遵守网站自身访问和下载规则。

3. 收藏夹

- 查看已收藏的素材。
- 支持取消收藏。
- 支持多选及批量操作。
- 点击素材可查看详情。
- 收藏数据支持手动备份和恢复。

4. 下载管理

- 显示下载队列和任务状态。
- 支持多任务排队。
- 支持调整下载顺序。
- 支持暂停、继续、取消单个任务。
- 并发下载数量允许设置为1至5。
- 支持断点续传（取决于服务器支持情况）。
- 软件启动时询问是否恢复未完成任务。
- 软件崩溃后重启时尽可能恢复任务。
- 下载完成后检查文件大小、格式和基本可读性。
- 支持下载文件安全扫描和风险隔离。
- 不记录独立运行日志。
- 不限制下载速度，遵循网络及来源服务器能力。

5. 本地素材管理

- 统一查看软件下载安装的素材。
- 自动按素材类型分类：图片、视频、音乐、音效、字体、模板等。
- 默认统一列表视图。
- 列表主要显示文件名称和大小。
- 支持关键词搜索。
- 不提供额外的属性筛选和排序功能。
- 支持多选、批量删除、格式转换、压缩等适用操作。
- 支持右键菜单：预览、打开、重命名、删除、格式转换等。
- 支持拖拽文件到其他文件夹整理。
- 支持查看文件大小、格式、创建时间、修改时间等属性。
- 支持复制文件路径。
- 支持“打开文件位置”，通过 Windows 文件资源管理器定位文件。
- 支持软件内预览，也可调用系统默认程序打开。
- 不支持批量导入用户已有素材。

6. 素材详情页

展示：

- 素材名称。
- 素材预览。
- 素材类型。
- 文件大小。
- 分辨率或清晰度（适用时）。
- 视频、音乐、音效时长。
- 免费、付费或会员专享状态。
- 来源网站及来源链接。
- 版权和授权说明。
- 下载操作。
- 收藏操作。

明确禁止下载或授权不明的素材，显示醒目的版权风险提示并阻止下载。

三、搜索结果卡片规范

搜索结果卡片需要遵守以下规则：

项目| 是否显示
素材封面| 显示
素材名称| 显示
免费/付费标签| 显示
明确版权风险提醒| 必要时显示
视频、音乐、音效时长| 显示
文件大小| 显示
来源网站名称和图标| 不显示
清晰度、分辨率| 详情页显示
发布时间| 不显示
收藏按钮| 不显示
快速下载按钮| 显示
复制来源链接| 详情页或右键菜单
右键菜单| 支持
多选| 支持

交互规则：

- 点击封面：直接预览。
- 点击素材名称：进入详情页。
- 点击快速下载：加入下载流程。
- 右键：预览、下载、收藏、复制来源链接等。
- 多选后：统一收藏或执行支持的操作。

批量下载前统一显示文件数量和预计占用空间，确认后加入下载队列。

四、下载安全与版权

版权规则

- 尊重素材网站的使用条款。
- 不绕过付费、登录、会员或其他访问限制。
- 明确禁止下载的素材禁止下载。
- 授权不明的素材禁止直接下载，并提示用户核实授权。

文件安全

- 下载前检查文件类型和风险。
- 对可疑文件阻止下载。
- 下载完成后进行安全扫描。
- 有风险的文件进行隔离。
- 用户可以确认风险后手动恢复隔离文件。
- 安全扫描不替代 Windows Defender。

下载异常

- 支持断点续传（服务器支持时）。
- 下载失败显示原因。
- 支持重新下载。
- 不检查磁盘剩余空间的额外预警。

五、素材处理工具

格式转换

支持常见图片、音频、视频格式转换。

- 支持批量转换。
- 支持手动调整图片质量。
- 支持手动调整音频码率。
- 支持手动调整视频分辨率和码率。
- 不提供转换前后对比预览。
- 转换失败显示原因，可重新转换或删除失败任务。

压缩工具

- 支持图片压缩。
- 支持音频压缩。
- 支持视频压缩。
- 支持批量压缩。
- 自动选择压缩程度。
- 不显示预计节省空间。
- 默认覆盖原文件，但必须先确保压缩成功，再替换原文件。
- 压缩失败保留原文件，并显示失败原因。

视频截图

- 支持手动指定时间截图。
- 支持按照时间间隔自动截取多张图片。
- 不提供视频剪辑功能。

音频截取

- 支持设置起始时间和结束时间。
- 截取后另存为新文件。
- 不支持音频合并。

图片基础编辑

支持：

- 裁剪。
- 旋转。
- 水平翻转。
- 垂直翻转。
- 调整图片尺寸。

不支持图片水印和去背景功能。

六、系统设置

- 可设置下载并发数（1至5）。
- 可设置下载保存目录。
- 可选择软件安装目录。
- 支持手动备份收藏、下载历史和设置。
- 支持通过备份文件迁移至另一台电脑。
- 备份文件不设置密码。
- 支持清空收藏、下载历史和个人设置，但保留下载素材。
- 清空数据前二次确认。
- 清空后不可撤销。
- 缓存每7天自动清理一次，不提供关闭开关，后台执行。

七、安装与卸载

- 支持自由调整窗口大小。
- 支持最大化和最小化。
- 不支持全屏和窗口置顶。
- 关闭窗口直接退出，不驻留系统托盘。
- 不开机自启动。
- 安装后创建桌面和开始菜单快捷方式。
- 安装时允许选择安装目录。
- 卸载时删除程序及相关数据和下载素材，必须在卸载确认界面醒目警告用户。

八、首版开发优先级

第一阶段：核心软件

必须先实现：

1. 主界面和导航结构。
2. 素材搜索。
3. 搜索结果分页。
4. 素材预览。
5. 素材详情页。
6. 收藏夹。
7. 下载队列。
8. 本地素材管理。
9. 基础设置。

第二阶段：素材处理

1. 图片、音频、视频格式转换。
2. 图片、音频、视频压缩。
3. 视频截图。
4. 音频片段截取。
5. 图片基础编辑。
6. 批量处理。

第三阶段：稳定性和完善

1. 下载断点续传。
2. 下载任务恢复。
3. 文件安全扫描。
4. 重复文件识别。
5. 数据备份与恢复。
6. 缓存自动清理。
7. 安装、卸载及异常恢复测试。

九、验收标准

首版必须达到：

- 软件能够正常安装、启动和退出。
- 首页、导航、搜索、详情页之间切换正常。
- 搜索结果每页20条，分页工作正常。
- 素材预览能够正常使用。
- 收藏和取消收藏正常。
- 下载任务能够排队、暂停、继续和取消。
- 批量下载前能显示文件数量及预计占用空间。
- 下载完成后能正确保存到本地目录。
- 本地素材能够搜索、预览、重命名和删除。
- 软件异常关闭后，数据不会无故丢失。
- 版权限制和文件风险提示能够正常工作。
- 不得将模拟数据伪装成真实搜索结果或真实下载成功状态。

十、开发原则

1. 优先开发真正可运行的软件，不只制作静态界面。
2. 每完成一个阶段，都要进行实际功能测试。
3. 所有按钮必须具有真实功能。
4. 不允许用虚假下载进度代替真实下载。
5. 网络搜索接口应采用可替换的适配器设计。
6. 对不支持的素材网站明确提示，不伪造搜索结果。
7. 所有文件操作必须进行异常处理。
8. 重要文件替换前保留原文件，防止数据损坏。
9. 软件界面使用简体中文。
10. 优先保证 Windows 笔记本上的稳定运行。
