# 素材源可行性核实（国内站点）

> 核查日期：2026-11-10。本文只做只读核实，不改代码、不改既有规划。
> 标注规则：**【已核实】**＝本次实际打开官方页面或官方 PDF 读到原文；**【未核实】**＝未找到官方一手依据；**【推测】**＝基于行业惯例或相邻证据的判断，不能当结论用。
> 免责：条款会变，接入前请以当日官网原文为准；本文不构成法律意见。

## 0. 结论摘要

1. **Pixabay 不是需求指定的，是「有公开 API 的免费源」这一技术约束下的默认起点**。全仓库（含归档需求文档）没有出现过任何国内站点名，也**没有候选源对比记录**。
2. 国内 8 个主流站里，**只有 4 家存在面向第三方的接口形态**：视觉中国、站酷海洛、千图网（含 2026 年的 MCP）、摄图网（仅见入口、无公开文档）。其余 4 家（花瓣、包图、觅知、昵图）**没有公开 API**。
3. 这 4 家的接口**都不是「免费自注册即用」**：视觉中国、站酷海洛、摄图网要商务/客户经理开通；千图 MCP 需要账号 OAuth 或 API Key，并按点数扣费。
4. 国内站**普遍在条款里明确禁止爬虫/自动化批量获取**：视觉中国、站酷（含海洛品牌）、花瓣、包图有直接原文；摄图有「防盗刷系统」；千图在授权书里禁止「大批量下载囤积」。
5. 因此现实只有两条路：**站内浏览 + 用户手动下载**（已实现，零合规风险但无结构化检索），或**走开放平台商务接入**（能结构化检索，但要企业资质与付费）。「自己写适配器去抓国内站」这条路**不可行**，也不该做。

### 1.2 当时给的理由（原文，不是我的补充）

`archive/开发文档_20261108.md` §8.2「理由」只有两条：

1. 六类素材里只有部分有合法公开接口：图片/视频（Pixabay、Pexels、Unsplash 确定）、音乐/音效（Pixabay，开放程度需以官方文档为准）、字体（Google Fonts Developer API，但语义是「字体下载站」不是「素材搜索」）、设计模板（**没有可用公开接口，确定没有**）。
2. 首版的价值是验证「搜索 → 下载 → 管理」这条链路能否跑通，不是比内容多少。单源让故障面最小。

§8.1 另有一条与选源相关的理由：若卡片完全不显示任何来源信息，「可选源会被压缩到只剩 Pixabay 一家」。

**没有。** 具体核查方式与结果：

**结论**：Pixabay 是「先找一个有合法公开 API 的免费源，把链路跑通」的务实选择，理由写在文档里；**「为什么不是国内站」这个问题，当初没有被讨论过，也就没有留下理由**。现在用户提出「只接国内素材网站」时，属于新增约束，不是需求被违背。

- **条款**：【已核实】《网站用户协议》（https://www.vcg.com/help/website-terms ，2026-03-13 生效）5.5(2) 禁止「使用任何数据挖掘程序、爬虫、机器人、自动化程序或其他类似技术手段，对平台内容进行抓取、采集、提取、监测或批量获取」；6.2 禁止违反 robots.txt 及使用自动化工具访问/抓取；5.4 未经书面授权不得把平台内容用于第三方 AI 产品或服务。
- **登录/付费**：【已核实】需注册账户并取得用图授权；具体费率与免费额度页面未列，【未核实】。
- **防盗链**：【未核实】未做逐站实测（见 §5 方法）。

#### 站酷海洛（hellorf.com）
- **API**：【已核实】`open.hellorf.com` 公开文档列出对接指南：先**咨询客户经理**（hellorf-mkt@zcool.com.cn），再在登录态下取得 client_id / client_secret（正式与测试各一份）；接口覆盖搜索、分类搜索、专题搜索、相似搜索、详情、购买、购买记录、授权书下载；文档明说「购买返回的尺寸由商务谈定」。

## 3. 两条可行路线

### 路线 A：站内浏览 + 用户手动下载（已实现）

**能覆盖**：全部 8 家 + 图虫等，随站点改版自动生效，不依赖对方接口。
**合规**：不自动抓取、不绕过登录/付费/下载限制，符合归档需求文档「遵守网站自身访问和下载规则」「不绕过网站登录、付费或下载限制」。
**代价**：
- 没有结构化搜索结果，素材不会自动进「本地素材」库（需要用户手动保存后再由本地素材管理接管）；
- 部分站点可能限制在内嵌浏览器里登录（风控/第三方登录），需要逐站实测；
- 体验割裂：用户在站内找到图，仍要自己「另存为」。

### 路线 B：走开放平台 API

**能覆盖**：视觉中国、站酷海洛、千图（含 MCP）、摄图（待确认），可拿到结构化结果、详情、下载与授权书。
**合规**：走官方通道，条款风险最低。
**代价**：
- 4 家都要**商务/企业资质**，不是个人开发者自助注册；
- 按购买或用量**付费**，且视觉中国/海洛的接入声明通常限制「不得把素材提供给第三方使用」——对一个免费桌面软件，成本与责任都要重新评估；
- 每家协议不同，适配器要分别做；接口变更也由对方掌握。

### 路线 C（建议的折中，供决策）

保留现有 Pixabay/Pexels 作为**默认可用的免费源**（无需用户付费、已验完），把「国内站」定位为**浏览入口**；若确需结构化接入国内素材，优先评估**千图 MCP**（形态最接近，且有明确的商用授权查询工具），其次再谈视觉中国/海洛的商务合作。不建议为任何国内站自建抓取适配器。

## 5. 未核实项与验证方法

以下均在本文标注为【未核实】，接入前需补：

1. **防盗链**：本轮未逐站实测。方法：取一张详情页图片直链，分别用「带 Referer = 站点页面」与「不带 Referer / 带第三方 Referer」请求，比较 HTTP 状态码与响应体。若不带 Referer 即 403，则存在 Referer 防盗链。
2. **摄图网 API**：接口文档、申请条件、报价、是否支持个人开发者。
3. **觅知网条款原文**、**昵图网条款原文**、**站酷海洛自身（非站酷主站）的禁止抓取条款**。
4. **千图 MCP 的商用授权范围**：`download_material` 拿到的文件能否随第三方软件再分发，需要读它的授权说明。
5. **各站「内嵌浏览器能否登录」**：花瓣、包图等对第三方 WebView 登录是否有限制。
6. **视觉中国/海洛的费率与最低合作门槛**。
