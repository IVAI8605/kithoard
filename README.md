# Kithoard 栖材坞

本地素材中转站：在 Pixabay、Pexels 找素材，下载到本地，做格式转换、压缩与简单编辑；收藏与下载记录都保存在本机，可备份迁移。

## 功能

- **搜索**：Pixabay、Pexels 双源，按来源分组展示，组内独立翻页；Key 只保存在本机。
- **下载**：队列、并发 1–5、断点续传、暂停/继续/取消/重试、崩溃恢复；下载前后都有安全检查，风险文件进隔离区。
- **本地素材**：查看、打开、定位、改名、移动、删除到回收站、属性面板；缺失文件保留记录并标记。
- **图片处理**：JPG/PNG/WebP/AVIF 转换，压缩（原子替换），裁剪、旋转、翻转、调整尺寸；批量执行。
- **音视频处理**：视频转码、压缩、截图；音频转码、压缩、截取；FFmpeg 随包，不依赖系统安装。
- **收藏夹**：收藏/取消、批量收藏、筛选与分页。
- **备份迁移**：导出/导入 JSON 备份，不含素材文件与 API Key；导入按远程标识重映射，路径缺失不阻断。
- **清空数据**：按收藏、下载历史、个人设置或全部清空；明确保留已下载的素材文件。
- **网站导航**：受限站内浏览，权限全拒、登录与外部协议转系统浏览器、页面下载拦截；最近访问 10 条。
- **设置**：保存目录、并发数、缓存占用与清理、素材源开关与 Key。

## 安装

- **安装包**：`Kithoard-Setup-<版本>-x64.exe`，可选安装目录，创建桌面与开始菜单快捷方式；卸载默认保留数据库与已下载素材。
- **免安装版**：解压 `Kithoard-<版本>-x64.zip`，运行 `Kithoard.exe`。

数据位置：`%APPDATA%\Kithoard\`（数据库、缓存、日志、隔离区）。卸载不会删除该目录。

## 开发

```bash
npm install
npm run fetch:ffmpeg   # 下载 FFmpeg 静态二进制到 resources/bin（约 200 MB，不入库）
npm run dev            # 开发运行
npm run gate           # 六道门禁：类型、lint、单测、构建、更新日志
npm run pack:dir       # 免安装解包产物
npm run build:win      # NSIS 安装包
```
